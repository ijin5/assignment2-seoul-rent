# 서울 전월세 지역 비교

## 공개 앱

배포된 앱은 [서울 전월세 지역 비교](https://seoul-rent-comparator.ijin500hp.workers.dev/)에서 확인할 수 있습니다.

서울 열린데이터광장의 전월세 실거래 API를 사용해 접수연도와 지역별 거래를 불러옵니다. 월세 거래는 사용자가 정한 전환율로 전세 환산보증금을 계산한 뒤, 전용면적 1㎡당 중앙값을 비교합니다. 첫 화면은 저장된 요약 자료를 즉시 표시하고 최신 API 자료를 뒤에서 갱신합니다.

앱은 서울 법정동 경계 GeoJSON을 사용해 서울 전역의 동별 색상 지도를 표시합니다. 웹 첫 화면은 2026년 5.0% 전환율 기준 요약 자료로 열리며, API 전체 자료를 받은 뒤에는 사용자가 선택한 전환율과 필터를 실시간으로 반영합니다.

## 저장된 분석 노트북

서울시_전월세_API_지역비교.ipynb에는 API 키 로드, 페이지 단위 수집, 로컬 캐시, 전세 환산, 지역별 비교와 월별 추이가 순서대로 저장되어 있습니다. 노트북은 이 폴더의 상위 폴더인 lecture04_spatial_data_analysis/.env에서 SEOUL_API_KEY를 읽습니다. 키 값은 노트북 출력에 표시하지 않습니다.

## 로컬 앱 실행 준비

1. 상위 폴더의 .env에 SEOUL_API_KEY가 설정되어 있어야 합니다.
2. Python 3으로 scripts/setup_local_secret.py를 실행하면 키를 출력하지 않고 이 앱 폴더에 로컬 Worker용 .dev.vars를 만듭니다. .dev.vars는 Git에서 제외됩니다.
3. Node.js 환경에서 이 폴더로 이동해 npx wrangler dev를 실행합니다.

## 법정동 지도 경계

웹 지도는 downloaded data/6주차/LSMD_ADM_SECT_UMD_서울/LSMD_ADM_SECT_UMD_11_202609.shp의 서울 법정동 경계를 사용합니다. 원본은 EPSG:5186, CP949 인코딩이며, 웹용 GeoJSON은 EPSG:4326으로 변환하고 15m 허용오차로 단순화했습니다. 생성된 public/seoul_legaldong.geojson에는 서울 법정동 467개가 들어 있습니다.

경계 파일을 다시 만들 때는 과제 앱 폴더에서 ../../.venv/bin/python scripts/build_seoul_legal_dong_geojson.py를 실행합니다. 앱은 API의 자치구명과 법정동명을 함께 사용해 경계와 결합합니다.

## 저장 요약본 만들기

요약본을 새로 만들려면 로컬 Worker를 실행한 상태에서 다음 명령을 사용합니다.

```sh
../../.venv/bin/python scripts/build_rent_snapshot.py --year 2026
```

스크립트는 `http://127.0.0.1:8787`의 Worker API를 통해 서울시 자료를 페이지 단위로 수집하고, 차트와 지도에 필요한 통계만 `public/rent_snapshot_2026.json`에 저장합니다. 요약본에는 API 키나 거래별 상세 자료를 넣지 않습니다.

Worker는 성공한 API 페이지를 Cloudflare edge와 브라우저에서 하루 동안 재사용하도록 응답합니다. 서울시 데이터는 하루 1회 갱신되므로 이후 방문에서 전체 페이지를 다시 제공처에 요청하지 않도록 합니다.

## 배포 준비

Cloudflare Workers에 SEOUL_API_KEY를 secret으로 등록한 뒤 Wrangler로 배포합니다. API 키는 브라우저 코드에 넣지 않습니다. 요약본과 법정동 경계는 공개 정적 자료이며, 키는 서버 Worker secret으로만 보관합니다.

## 비교 기준

- 신고 접수연도로 최근 3년 자료를 조회합니다.
- 전세 환산보증금 = 보증금 + 월세 × 12 ÷ 전환율입니다.
- API의 보증금과 월세 단위는 만원입니다. 지역별 비교는 거래별 환산보증금(만원)을 전용면적으로 나눈 값(만원/㎡)의 중앙값입니다.
- 지역은 법정동 기준입니다. 선택한 구 안에서는 법정동끼리, 서울 전체에서는 자치구와 법정동을 합친 이름으로 비교합니다.
- 월별 추이는 신고 접수연도가 아니라 실제 계약일 기준입니다.
- 지도는 자치구명 기준으로 공간 조인하며, 조인 전후 경계 행 수와 매칭 자치구 수를 노트북에 기록합니다.
- 최신 API 자료는 거래 신고와 정정 시점에 따라 반영 시차가 있을 수 있습니다.

## 전송 구간 관련

서울 열린데이터광장 API는 이 작업에서 HTTP 주소로 정상 응답하는 것을 확인했습니다. API 키는 브라우저에 보내지 않고 Worker secret으로 보관하지만, Worker에서 서울시 API까지의 HTTP 연결은 암호화되지 않습니다. 사용자가 이 전송 위험을 확인하고 진행하기로 했습니다. 실제 공개 운영 전에는 API 제공처의 HTTPS 지원 여부와 해당 키의 재발급·접근 제한 기능을 확인하세요.
