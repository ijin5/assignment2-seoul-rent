계산 방법과 자료 범위

전세 환산보증금 = 보증금 + 월세 × 12 ÷ 전환율입니다. 지역별 수치는 거래별 환산보증금을 전용면적으로 나눈 뒤 중앙값을 계산합니다. 전환율과 건물 용도를 바꾸면 결과도 다시 계산됩니다.

접수연도는 신고가 접수된 연도이고, 월별 추이는 실제 계약일 기준입니다. 처음에는 저장된 2026년 요약 지도를 표시하고 서울시 API 자료를 뒤에서 갱신합니다. 서울시 API는 최근 3개 접수연도 자료를 제공하며 하루 1회 갱신됩니다. 거래 신고와 정정 시점에 따라 최신 거래 반영 시차가 있을 수 있습니다.

지도와 막대그래프는 거래 자료의 자치구명과 법정동명을 기준으로 비교합니다. 지도에는 서울 법정동 경계 467개를 표시하며, 해당 경계는 2026년 9월 자료입니다. 경계 자료와 거래 자료 사이의 이름이 맞지 않는 지역은 지도에서 자료 없음으로 표시합니다.

서울시 API 호출은 서버에서 처리합니다. 브라우저에는 API 키가 전달되지 않습니다. 서울시 API 연결 구간은 HTTP로 제공되어 전송 구간의 암호화가 적용되지 않습니다.
